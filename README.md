### Introduction

One sample project for digital recode of speech, delivered in ceremonies of Graduates and Undergraduates by The President ***ShuGuo Wang***, Xi'an Jiaotong Uni.


### Pipeline
Download video or audio file from Bili station, then transcribe them with whisper model(large-v3). After fetching the model packages and require modules(I choose to use GPU speeding up task and there version of NVIDIA-CUDA is cu12), Start transcription task. While finished above, We need extensively listen for every output, it takes long period of time, Then Planning to Viz. with script, generate website, deploying with this repo in github platform.
